# P6 桌面版验收清单（Tauri 壳 + 打包验证）

> 适用：`src-tauri/target/release/bundle/nsis/research-workbench_0.1.0_x64-setup.exe`
> 依据：PRD 10.4 M2 完成定义第 6 条（启动 → 向导 → 阅读/问答/导出全链路 + 退出联动）+ P6 专项。

## 准备

- [ ] 准备测试 vault（任意空目录，如 `D:\test-vault`）
- [ ] 准备 1-2 个测试 PDF（arXiv 论文最佳，可验证元数据补全）
- [ ] 准备 DeepSeek API Key（对话必需）；SiliconFlow Key 可选（缺省时 RAG 降级，问答无来源）
- [ ] 确认 3001-3010 端口空闲（`netstat -ano | findstr 300` 无监听）

## A. 安装与目录结构

- [ ] 双击 setup.exe 安装（per-user，默认装到 `%LOCALAPPDATA%\Programs\research-workbench\`）
- [ ] 安装目录含 `research-workbench.exe` 与 `resources\backend-server\`（backend-server.exe + _internal/）
- [ ] 桌面/开始菜单出现"知微 · 科研工作台"快捷方式

## B. 首次启动 + 向导（P1 联调）

- [ ] 双击启动，**无后端控制台窗口弹出**（console=False 生效）
- [ ] 打开任务管理器：出现 `backend-server.exe` 进程（壳自动拉起后端）
- [ ] 窗口显示首次启动向导（3 步：选择数据目录 / 配置 AI 服务 / 连通性测试）
- [ ] 步骤 1：点"选择文件夹" → 系统目录选择器可用 → 选测试 vault
- [ ] 步骤 2：填 DeepSeek Key（SiliconFlow 可留空）
- [ ] 步骤 3：点"测试连接" → DeepSeek 显示"连接正常"（SiliconFlow 显示"未配置"）
- [ ] 完成 → 进入工作台，侧边栏/顶栏正常渲染

## C. 配置与进程落盘

- [ ] `resources\backend-server\.env` 存在，含 `VAULT_PATH=` 与 `DEEPSEEK_API_KEY=`（exe 旁可写路径生效）
- [ ] `resources\backend-server\logs\app.log` 有启动日志（索引扫描完成）
- [ ] vault 目录自动生成 `.kb\`（literature.json / chroma_db）
- [ ] 后端端口 = 3001（或 3002+，被占则递增；`netstat -ano | findstr backend-server 的 PID`）

## D. 全链路功能（M2 验收 6 条核心）

- [ ] **导入**：文献库 → 导入 → 选 PDF → 元数据自动补全（标题/作者/年份）→ 列表可见
- [ ] **阅读**：打开 PDF → 翻页/缩放正常
- [ ] **划词**：选中文字 → 浮层出现 → "转笔记引用"（新建笔记含页码+摘录）/"问 AI"/复制
- [ ] **笔记**：新建笔记 → 编辑 → 自动保存 → vault\笔记\ 出现对应 .md（frontmatter 含 cites）
- [ ] **引用**：笔记尾部参考文献列表渲染；文献详情页显示反向引用
- [ ] **AI 问答**：全局问答（配置了 SiliconFlow 时回答附来源；未配置时正常降级无来源）
- [ ] **单篇问答**：阅读器内问 AI，回答限定当前文献
- [ ] **研究任务**：AI 面板切"研究任务" → 发起"找出本地知识库中关于 RAG 的资料" → 看到工具步骤事件流 + 最终答案
- [ ] **会话记忆**：新建/切换/删除会话；`vault\.kb\conversations.json` 可读
- [ ] **导出**：参考文献列表导出 docx（GB/T 7714）；BibTeX 导出 .bib
- [ ] **元数据编辑**：文献详情 → 编辑标题/年份 → 保存 → 导出/引用同步变化

## E. 持久化与重启

- [ ] 正常退出应用 → 重新启动 → **向导不再出现**（配置已持久化）
- [ ] 重启后笔记/文献/会话全部还在
- [ ] 阅读进度（页码）在重启后恢复（若测过阅读）

## F. 退出联动（P6 专项）

- [ ] 关闭主窗口 → 任务管理器 `backend-server.exe` 进程**消失**
- [ ] 端口释放（`netstat -ano | findstr 3001` 无监听）
- [ ] 无残留进程（重启前确认）

## G. 索引自愈（P3，可选）

- [ ] 退出应用 → 删除 `vault\.kb\chroma_db` 内部分文件 → 启动 → 后端自动删库重建（logs 出现"chroma 索引已删除，等待全量重建"→ 索引扫描完成；kb/status chunks 恢复）

## H. 回归（开发模式，可选）

- [ ] 浏览器开发模式（vite dev + uvicorn）功能无回归——`api.ts` 浏览器态仍走 localhost:3001

## 问题取证（遇到异常时）

| 现象 | 取证位置 |
|---|---|
| 启动即退出/白屏 | `resources\backend-server\startup-error.log`（启动异常落盘） |
| 后端异常 | `resources\backend-server\logs\app.log`（滚动日志） |
| 端口冲突 | 换端口重试（壳自动探测 3002+） |
| 功能异常 | 截图 + 上述日志一并反馈 |

## 通过标准

A-H 全部勾选（G/H 可跳），即满足 PRD 10.4 第 6 条"Tauri 桌面程序：启动 → 向导 → 阅读/问答/导出全链路可用；关闭应用后端进程联动退出"，P6 正式收官。
